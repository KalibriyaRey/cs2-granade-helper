	Что умеет программа (Функционал)
==================================================
        CS2 GRENADE HELPER - ИНСТРУКЦИЯ
==================================================
ОСНОВНОЕ ПРЕДНАЗНАЧЕНИЕ:
Программа создана для быстрого просмотра видео-гайдов по раскидкам гранат 
прямо во время матча в CS2 без использования сторонних девайсов.

ГОРЯЧИЕ КЛАВИШИ:
--------------------------------------------------
[ALT] (зажать)      - Вызов графического меню (колеса).
[Мышь]              - Наведение на сектора.
[ЛКМ]               - Выбор карты/типа/видео.
[A]                 - Предыдущая страница (внутри меню).
[D]                 - Следующая страница (внутри меню).
[Shift + ЛКМ]       - Добавить/Удалить видео из ИЗБРАННОГО.
[ALT] (отпустить)   - Скрыть меню и остановить видео.

КАК ДОБАВЛЯТЬ СВОИ ВИДЕО:
--------------------------------------------------
1. Откройте папку 'assets'.
2. Выберите нужную карту (например, mirage).
3. Выберите тип гранаты (smoke, molotov или flash).
4. Закиньте туда видео в формате .mp4.
5. Название файла будет отображаться в меню программы.

ФУНКЦИИ И ОСОБЕННОСТИ:
--------------------------------------------------
- Авто-сортировка: Новые файлы всегда в начале списка.
- Избранное: Ваши лучшие раскидки доступны в один клик.
- Пагинация: Поддержка неограниченного количества видео (по 8 на страницу).
- Оверлей: Окно программы всегда поверх игры.
